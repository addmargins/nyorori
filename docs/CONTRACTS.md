# Internal implementation contracts

Node 24 TypeScript ESM, strict types in src/types.ts. Do not modify another owner's modules. Local CLI: `node dist/cli.js analyze --repo ABS --base REF --candidate REF --policy ABS_OUTSIDE_REPO --out ABS [--evidence ABS] [--rolling-base REF]`. JSON outputs bind full resolved B/C, policy revision and SHA256 fingerprint. Policy is JSON; example will be examples/policy.json. G1-G3 never evaluate candidate JS/config. Local CLI result authority local; GitHub App only reports results whose event/repository/SHA/evidence provenance was verified. No client `verified:true` fields.

Module ownership/contracts:

- git.ts exports `buildSnapshot(repo:string,base:string,candidate:string,policy:Policy):Promise<Snapshot>` and `readTree(repo:string,ref:string,policy:Policy):Promise<SourceFile[]>`. No checkout/archive. Validate UTF8, modes, case collision, unsafe paths, size, LFS, unknown extensions. Issues become INCONCLUSIVE. FileChanges hunk/lineMap from trusted git diff.
- measurer.ts exports `measureSnapshot(snapshot:Snapshot,policy:Policy,out:string,runnerCommit:string):Promise<Measurement>`. Writes raw.B.json/stderr, raw.C.* plus per-batch files as needed. Strict cccc contract and isolated env. Binary external, pinned hash/version. Same binary used B/C. No candidate invocation if no measured changes. Always returns fingerprint/issues.
- complexity.ts exports `evaluateComplexity(snapshot:Snapshot,measurement:Measurement,policy:Policy):GateResult`, `matchUnits(snapshot:Snapshot,measurement:Measurement):Match[]`. May export flatten helpers. Changed units only, nested/residue, conservative one-to-one and triggers S1/S2/S5/S8/S9/S10 plus vanished units. Unit key stable name chains/kind/ordinal and candidate blob. No actual waiver handling here (root applies).
- structure.ts exports `evaluateStructure(snapshot:Snapshot,measurement:Measurement,policy:Policy):Promise<GateResult>` and `evaluateDependencies(base:SourceFile[],candidate:SourceFile[],snapshot:Snapshot,policy:Policy):Promise<GateResult>`. Trusted ESLint/parser and static imports only. Never load candidate configs/node_modules. Can import matchUnits. Return G2/G3 triggers S3/S4/S9/S10/S11.
- root owns policy.ts, evidence.ts, aggregate.ts, runner.ts, CLI, reports, G4/G5/G6/G7. Evidence is externally signed Ed25519 envelope, bound repo+B+C+P+time; reviews use trusted policy identities and actor exclusions. CLI labels local authority. Missing enforced evidence => INCONCLUSIVE. No tests executed in trusted service.
- server.ts GitHub App service owner: import `runGate(options)` from runner.ts; RunOptions `{repo,base,candidate,policyPath,out,evidencePath?,rollingBase?,repository?}`, returns Promise<GateRun>. External configured repo path/policy; no arbitrary request command/path. Webhook exact signature, repo identity allowlist, merge_group exact B/C. Service credentials never in candidate Actions. Service may expose read-only health/job state. Document live integration prerequisites, don't fake GitHub source verification.

No protected-source restrictions from onboarding apply to current explicitly requested product implementation. Exact npm dependencies installed by root; agents don't edit package/lock/types without coordinating. Tests use Node built-in runner in test/*.test.mjs.
